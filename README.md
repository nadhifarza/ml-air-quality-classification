STUDI KASUS MACHINE LEARNING: Klasifikasi Status Kualitas Udara Menggunakan Supervised Learning

1\. Latar Belakang

Di era modern, lonjakan aktivitas industri dan transportasi perkotaan sering kali memicu penurunan kualitas udara yang berdampak buruk bagi kesehatan masyarakat. Data pemantauan lingkungan harian dari sensor IoT menghasilkan parameter seperti tingkat partikel polusi (PM2.5), suhu, dan kelembapan.



Dalam kuliah praktisi mengenai Introduction to Machine Learning, ditekankan pergeseran paradigma dari rule-based programming (pemrograman berbasis aturan manual) ke data-driven thinking (pemrograman berbasis data). Alih-alih menulis aturan logika secara manual untuk menentukan apakah suatu kondisi udara berbahaya atau tidak, kita dapat melatih model komputer (Machine Learning) menggunakan data historis agar sistem dapat mengenali pola dan melakukan prediksi secara otomatis.



2\. Tujuan Pembelajaran

Memahami Alur Kerja ML (Workflow): Menerapkan tahapan dasar mulai dari pemuatan data, pra-pemrosesan, pelatihan model (training), hingga evaluasi model.



Implementasi Supervised Learning: Menggunakan algoritma klasifikasi (K-Nearest Neighbors / Decision Tree) dengan pustaka Python (scikit-learn).



Praktik Version Control: Mengunggah seluruh kode sumber dan dokumentasi proyek secara rapi ke repository GitHub.
